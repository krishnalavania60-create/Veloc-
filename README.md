# VELOCÉ — Beyond Speed. Beyond Limits.

A responsive automotive experience prototype with a live Three.js scene.

## Run
The site uses browser ES modules and CDN-hosted Three.js. For local testing, serve this folder through a local web server (for example VS Code Live Server) rather than opening `index.html` with `file://`. Internet access is required for the CDN libraries, Google Fonts and remote images.

## Included
- Cinematic landing page and responsive navigation
- Seven-car collection and selectable vehicle presentation
- Interactive Three.js procedural hypercar study with orbit, zoom and lighting controls
- Animated rear deck/engine-bay reveal
- Illustrative engine assembly with component selection and exploded-view controls
- Engineering laboratory, performance comparison and brand sections
- Mobile responsive layout and reduced-motion CSS support

## Accuracy and asset notes — important
The 3D car and engine are procedural educational visualizations, not exact scans or manufacturer CAD models. The vehicle silhouette is a generic hypercar study and is not an authentic Bugatti, Koenigsegg, Ferrari, McLaren, Lamborghini or Porsche model. The rear-deck animation and component separation demonstrate interaction mechanics; they are not certified reproductions of any specific vehicle's body-panel kinematics or engine architecture.

Collection photography is illustrative and remote. Replace with verified, licensed, model-specific images before publishing. For authentic model-specific 3D inspection, obtain appropriately licensed GLB/GLTF assets and rigged mechanical assemblies, then replace the procedural scene. Verify specifications against manufacturer sources before public release.
